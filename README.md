# 🛒 AuraCart - E-Commerce Website

AuraCart is a responsive e-commerce website built using **HTML, CSS, and JavaScript**. It provides a simple and interactive shopping interface for browsing products and managing a shopping cart.

## 🚀 Features

* 🛍️ Product browsing
* 🔎 Product search
* 🛒 Add products to cart
* ➕ Increase or decrease product quantity
* ❌ Remove products from cart
* 💰 Dynamic cart total
* 📱 Responsive user interface
* 🎨 Clean and modern design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
